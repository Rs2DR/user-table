# Проект

## 👉 [Демо](https://jazzy-tiramisu-86703d.netlify.app/)

## 📋 Описание

Проект представляет собой таблицу управления пользователями с базовым CRUD-функционалом.

### Возможности:

- Таблица с 4 колонками:
  - Имя
  - Дата
  - Возраст
  - Действия

- Действия включают:
  - Редактирование пользователя
  - Удаление пользователя

- Кнопка «Добавить» (над таблицей)
  - Открывает модальное окно
  - То же окно используется для редактирования (с предзаполненными данными)

- Строка поиска
  - Фильтрация по всем колонкам таблицы

## 🧩 UI/UX детали

- Модальные окна для создания и редактирования пользователей
- Выбор даты через popover с calendar picker
- Простая favicon

## 🛠️ Стек технологий

- TypeScript
- Ant Design (antd)
- Day.js
- ESLint (Atomizing config)

- Commitlint

## 🚀 Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

### Просмотр production-сборки

```bash
npm run preview
```

### Проверка кода (lint)

```bash
npm run lint
```
